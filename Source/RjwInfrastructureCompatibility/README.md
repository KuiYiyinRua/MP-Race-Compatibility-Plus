# 联机基础层补充程序集

本项目为 `323_new.xml` 对应环境提供通用基础层修正，输出 `Meow.RjwInfrastructure.dll`。当前轮次已结束，并按用户要求暂停。候选尚未通过稳定性测试，未部署到正式模组目录。

实现范围：

- 音效回调完整隔离 `Verse.Rand`，异常路径也恢复外层状态。
- 数值随机工具在联机中使用模拟随机流，避免系统运行时间种子绕过已有隔离。
- 字体高度测量延迟到界面入口，避免加载线程访问 Unity 字体资源。
- 继承方法的反射目标统一到实际声明类型，修复兼容补丁注册失败。
- 周期事件组件重复构造时恢复静态候选池的初始种子，保留首次构造的权重。
- 全局日期计算和周期事件使用确定的家园、派系上下文，并在 finalizer 中恢复。
- 周期事件目标不再取决于客户端当前查看的地图。

它与现有核心程序集并用。构建时链接已存在的音效隔离源码，不重新构建核心项目；目标方法和关键 IL 形状不匹配时会报 `REQUIRED_TARGET_FAILURE`。

验证驱动、历史失败证据、冻结候选和逐轮状态在 `BuildValidation/RjwInfrastructure_20260911`。驱动仅供隔离测试，包含中性夹具、重复构造检查、保存前后断言、双端字段比对、派系数据重组、同身份冷重连，以及中段和结束检查。测试驱动 DLL 不属于运行补丁交付物。

```powershell
dotnet build Source/RjwInfrastructureCompatibility/RjwInfrastructureCompatibility.csproj -c Release
```

构建依赖工作区对应的 RimWorld、Multiplayer、Harmony 和 Prepatcher API。验收必须绑定实际测试的 DLL 哈希，编译通过本身不代表联机稳定。

本轮结果（2026-09-11）：10 项静态检查通过；最新双地图存档首次加入、三轮同步断言和音效随机隔离断言通过。R8 在共享 tick 123782 检测到地图 0 随机状态失步，最后一致 tick 为 123721。官方双端诊断包、原始异常堆栈与冻结快照已经保存。尚未完成冷重连和长时间稳定性验收。

首个分歧调用读取到了不同的随机种子与计数，不能直接把该调用认定为根因。另有 YaOpt 并行面部绘制访问 Multiplayer 时间上下文的空引用异常待处理。后续需由用户恢复任务后继续排查。
