# MP Race Compatibility Plus

这是一个面向 RimWorld Multiplayer 的兼容性补丁模组，用于降低特定模组在多人游戏中的不同步风险，并修复部分联机状态、随机数和事件流程问题。

## 提交补丁的必要说明

提交者必须在 Pull Request 或提交说明中完整说明以下内容；缺少任一项的提交将不予接受：

1. **实现方式**：说明使用的 Harmony patch、前缀/后缀/转发补丁、状态同步方式、随机数隔离方式或其他技术方案，并指出关键入口和影响范围。
2. **补丁内容**：逐项列出修改或新增的文件、对应的原版/第三方方法，以及补丁解决的具体联机问题。涉及行为变化时，还必须说明单机与多人模式下的差异。
3. **实际测试情况**：明确说明是否进行过实际测试。必须提供测试环境（RimWorld 版本、Multiplayer 版本、相关前置/第三方模组）、测试场景、主机与客户端情况，以及测试结果。仅静态分析、编译通过或理论上可行，不视为实际测试。

建议同时附上日志、复现步骤、存档或其他可验证证据，并说明已知限制和潜在兼容性影响。

## 开发与验证

鼠族异象与地下扩展的实现和验证记录见 [Ratkin Anomaly+ / Underground+](Docs/Ratkin-Expansions-Multiplayer.md)。

提交前请确保项目可以正常编译，并在实际多人主机/客户端环境中验证补丁。涉及确定性、同步回调、随机数、跨地图或跨派系行为的修改，应特别测试加入、重连、读档和重复执行场景。

## 为何创建本仓库？

本仓库补充种族、DLC 交互和常用模组的多人兼容，并在保持模拟一致性的前提下减少部分性能开销。兼容范围依赖实际版本、功能和组合，不能保证任意整合包完全无失步。

## 文件排除

仓库不会提交本地编辑器目录、构建输出、`BuildValidation` 验证资料、程序集副本或其他机器相关文件；具体规则见 [`.gitignore`](.gitignore)。

## 多派系外交隔离

3.0.127 按玩家派系实例保存 Milira 开局敌对与和解状态，并分别处理好感度上限、重算和自然恢复。相同开局定义的不同派系也保持独立；正常交战不再被定期重置。实现范围和旧档行为见 [外交隔离说明](Docs/FACTION_DIPLOMACY_ISOLATION.zh-CN.md)。
