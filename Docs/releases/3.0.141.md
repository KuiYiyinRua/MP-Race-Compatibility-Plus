# MP-Race-Compatibility-Plus 3.0.141

2026-09-29 发布范围：完整 22 个生产程序集、对应源码、测试源码、工具和文档。

## 更新

- 将此前本地 3.0.140 的完整模块集合发布到创意工坊与 GitHub 源码库，包括独立的空袭兼容模块 1.0.6、剧情/派系隔离、保存性能与 RJW 基础设施等模块。历史实现与限制见 [3.0.140 记录](3.0.140.md)。
- 主程序集 3.0.141 与炮台休眠模块 1.5.0：联机启动时安装统一入口；入房配置比较后，客户端验证并导入房主的炮台开关与可安全热更新的本模组运行设置。不能安全应用的配置禁止手动绕过加入。炮台优化默认关闭，房间须开启 Multiplayer 配置同步。
- 包含已单独发布的 RaceTrio 1.1.5 Monolyn 生产模式菜单与重力柱滑条修复。

## 验证与限制

RimWorld 1.6 和 Multiplayer 0.11.5 本机依赖下，22 个生产项目完整编译通过。连接配置补丁的原生入房窗口 6 组断言和单地图双端短测通过：房主开关开、客户端关，客户端导入后两端冻结随机状态与 3 座炮台休眠判定相等，之后保持约 10,000 共享 tick 未报告不同步。

Desync-295–297 指向旧版客户端启动时关闭炮台模块却绕过配置提示加入；本版处理了这一入房漏洞。Desync-298–307 来自旧版 3.0.140/1.4.0，后段日志与轨迹不足以定位另一处可靠补丁；不宣称全部这些不同步已修复。完整整合存档的多地图、三次冷重连和 120,000 tick 长测未完成。所有玩家须更新**整个模组目录**并完全重启，保持文件一致。

源码中 `Patch_MpConfigHotSync` 是加入与配置事务边界；`TurretCombatSleep.Active` 是炮台模拟执行门控。单人游戏不启用联机休眠行为。出现新的不同步时，请保留第一次完整双端日志、联机存档或回放。
