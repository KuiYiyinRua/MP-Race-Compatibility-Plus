## 诊断与修复边界

Desync-466/467/468 的原生冰雾分支在主机多消耗三次共享随机数（两次偏移、一次旋转），随后相同种子的其他模拟调用出现计数差。交易与职位窗口是触发条件：一端本地镜头地图暂停，而另一张地图继续模拟。该分支原先使用 TickManager.Paused，经 MP 后读取本地 CurrentMap，造成两端条件不同。

NMC 0.9.8 的已审查程序集 MVID 为 579a0deb-6d02-484c-a4c7-0e75d0df2fbb。旧 RaceTrio 仅识别 0.9.6/0.9.7 的随机数所有者，重复改写使原生补丁失败并阻断冰雾隔离初始化。本次按精确 owner、类型、方法、程序集与 MVID 识别该已审查版本；其他未知版本不作通用放行。TaleNivarian 仅替换原生冰雾中的一个暂停查询，并要求匹配次数恰为一；单人和界面上下文保持原生暂停行为。
