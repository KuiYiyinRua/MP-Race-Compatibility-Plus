发布当前全部 22 个生产模块和现有实验功能，GitHub 同步完整源码、测试源码、工具及文档。包含 3.0.148–3.0.151 的主角认定、随机数与状态持久化、米莉拉穿梭机返航修复，以及涅瓦莲本体更新兼容和 Monolyn 补充程序集 1.1.8。武器法典同步存入、取出、神圣武器切换、落地取出及机械体切换，保留原生装备与工作行为；感谢 AzzyH 的设计参考。
