# 3.0.147（2026-10-03）

完整模组版本，包含全部 22 个生产模块及此前已本地部署的 3.0.146 改动。

- Desync-375：两端同 tick 经过妓院访客接受判定、相同的随机调用与访客换工作；客户端随后单独分配历史消息 ID。多人模式下仅将该流程的两条通知改为非历史消息，保留通知显示与接客模拟逻辑。
- Desync-378–380：三包首个采样分歧均为主机 `PitGate.Tick` 独有的 `Rand.MTBEventOccurs`。安装版深坑之门在 `Find.CurrentMap` 条件下有镜头震动随机判定。只隔离此纯视觉调用，保留事件生成的另一处 `MTBEventOccurs` 和全部门体状态变更。
- Desync-355/356/358：纳入 DesyncBatch 1.0.8 的 Ariandel 本地音乐随机数隔离候选。
- Desync-376/377：首个采样分歧涉及 AM 地图处理和搬运；现有窗口不足以确认上游原因，本版未对其实施推测性补丁。

22 个生产项目在隔离输出目录编译成功。已核对安装版妓院访客方法的两条历史通知调用，以及本机 RimWorld 1.6.4850 深坑之门的视觉与事件两处随机调用。新补丁尚未完成对应场景的双端重放、冷重连或代表性长测，因此本版标记为**编译及静态核验通过，运行未验证**。所有玩家必须安装相同完整版本并完全重启。原始 ZIP、逐包轨迹和构建哈希保留在本地 `BuildValidation/DesyncEvidence/Desync375-380_20261003/`。
