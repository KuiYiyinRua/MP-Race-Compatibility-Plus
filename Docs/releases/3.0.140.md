# 3.0.140 完整本地发布 / Full local release

本次按用户明确要求完整部署当前源码中的全部 22 个生产项目。核心版本 3.0.140，空袭独立修复模块 DesyncBatchCompatibility 1.0.6。保留所有模块原有设置、默认状态及目标模组条件；包含功能不等于自动开启实验优化。

## 本次内容

- 补齐空袭模拟修复：轨迹随机初始化、镜头更新频率隔离、绘制状态恢复、轨迹存档和明确目标地图。
- 包含主教二型储存滑条、机械体发型/颜色同步，及当前主模块所有已有兼容代码。
- 重建并部署所有独立兼容模块、炮台休眠与渡鸦工业优化；MeleeAnimation、RavenCompatibility、RatkinUnderground 条件加载目录全部保留。
- 此前仅作为候选保留的 FactionPurge、FactionStoryIsolation、LatestSavePerformance、PerformanceCompatibility、RjwInfrastructureCompatibility 也按本次全量部署要求纳入。
- 发布包包含运行文件、完整 Source、Tests、Tools 和 Docs。测试驱动只提供源码，不安装其运行程序集。派系清理必须由房主主动执行，完整整合存档的历史清理测试曾被残留引用拦截；此次未声称该限制已修复。

## 验证与限制

22 个生产项目本轮全部编译成功；检查每个程序集版本/MVID及对本轮主DLL的引用；空袭/滑条/发型静态检查30项通过。部署后与归档候选、ZIP每个文件进行SHA256核对。

本次是用户要求的完整部署：**已编译并静态检查，最终完整组合未做新的双端运行验证或完整存档长测**。此前局部候选的双端功能测试不能代表本次重新构建的22模块组合全部通过。帝国通讯呼叫舰船的用户故障仍未定位，不能因完整部署而称已修复。

## 使用

主机和所有客户端使用相同的完整模组文件，完全退出游戏后再安装并重启。仅重新进房不会加载新DLL。以发布包顶层 MP-meow-online-shop 为模组目录；保留 LoadFolders.xml 和三个条件目录，不要只复制主DLL。RimWorld、Harmony、Multiplayer 和各目标模组仍需单独安装。

后续完整重建：从模组目录运行 `Tools/Build-FullRelease.ps1 -OutputRoot <全新目录>`；清单在 Tools/full-release-projects.json。脚本先编译核心，再让各模块引用同轮核心，输出到隔离目录，不自行修改正式目录。
