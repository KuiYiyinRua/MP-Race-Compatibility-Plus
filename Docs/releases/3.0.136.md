# MP-Race-Compatibility-Plus 3.0.136

## 中文更新日志（2026-09-25）

- **Melpomene Avatar**：更新征召相关的联机兼容修复（3.0.133）。该修复由用户实机验证。
- **炮台战斗休眠实验版 1.3.0**：随包提供独立程序集 `1.6/Assemblies/Meow.TurretCombatSleep.dll`，设置默认关闭；开启后针对已核对的空闲炮台战斗逻辑减少不必要工作，不修改存档格式。无法确认适用结构的类型保留原逻辑。此版本仅完成编译与静态核对，未做游戏运行验证。
- **渡鸦工业流水线优化 1.0.0**：新增独立程序集 `RavenCompatibility/Assemblies/Meow.RavenIndustryOptimization.dll`。在多人游戏中可选启用，默认关闭；设置由房主同步并随存档保存。覆盖生产容量查询、无效调度记录清理及符合条件的普通传送带整段推进/堵塞移动休眠，其他路径保留原处理。

验证范围：Melpomene Avatar 修复由用户实机验证。炮台战斗休眠 1.3.0 与渡鸦工业优化 1.0.0 完成编译和静态核对；本次未对它们进行游戏运行、主客机联机或 TPS 验证。静态覆盖清单不代表所有第三方炮台、传送带实现或模组组合均已通过实测。

所有玩家使用完全相同的发布文件并重启。炮台实验开关和渡鸦优化开关均默认关闭。启用炮台实验时，所有联机玩家必须在模组设置中打开相同开关并重启；启用渡鸦优化前阅读 [渡鸦工业优化说明](../RavenIndustryOptimization.md)。范围及回退方式见[炮台休眠说明](../TurretCombatSleep.md)。关闭对应选项并保存可停用优化；如需移除独立模块，应在所有玩家退出游戏后操作。

## English changelog (2026-09-25)

- **Melpomene Avatar**: updates the multiplayer drafting fix (3.0.133). The user verified this fix in game.
- **Turret Combat Sleep Experimental 1.3.0**: includes the standalone `1.6/Assemblies/Meow.TurretCombatSleep.dll`, disabled by default in mod settings. When enabled, it reduces work in reviewed idle turret combat paths without changing save data. Types whose structure does not match retain their original behavior. This build received static checks only, with no in-game runtime verification.
- **Raven Industry Optimization 1.0.0**: adds the standalone `RavenCompatibility/Assemblies/Meow.RavenIndustryOptimization.dll`. It is opt-in for multiplayer and disabled by default; the host setting is synchronized and saved. It covers production-capacity queries, stale scheduler-record cleanup, and whole-line movement/sleep for eligible ordinary conveyors; other paths retain their original handling.

Validation: the user verified the Melpomene Avatar fix in game. Turret Combat Sleep 1.3.0 and Raven Industry Optimization 1.0.0 received build and static checks only; no game runtime, host/client, or TPS verification was performed for them in this release. Static coverage inventories do not establish runtime validation for every third-party turret, conveyor implementation, or mod combination.

All players must use identical release files and restart. Both the turret experiment and Raven optimization are disabled by default. When enabling turret sleep, all players must set the same mod option and restart. Review the [Raven optimization notes](../RavenIndustryOptimization.md) before enabling that option. Turret scope and rollback instructions are in the [turret sleep notes](../TurretCombatSleep.md). Disable and save the corresponding option to roll back an optimization. Remove a standalone module only after all players exit the game.
