# 3.0.138：联机交易窗口自动弹出设置

新增默认开启的「交易界面仅向发起玩家自动弹出（联机）」开关，位于本模组设置顶部，切换立即生效。

其他玩家发起据点或世界远行队交易时，本机不再自动切换到交易界面。远行队途中抵达据点时，也只向记录的发起者自动跳转。**其他玩家仍可主动打开交易入口查看**，共享会话和原有交易权限保持不变。关闭开关后恢复 Multiplayer 原有行为；各玩家独立设置。

原版及五个 DLC 的隔离主客机测试通过：据点交易、延迟抵达、遭遇交易各三轮，关闭开关对照一轮，双方主动查看/关闭后重开，以及 10,000 Multiplayer 共享 tick 烟测。未验证完整整合存档、冷重连或 120,000 共享 tick 标准长测。

重启游戏加载新 DLL，房间所有玩家应更新到同一补丁版本。详见 [设置与限制](../TradeWindowAutoOpen.md)。
