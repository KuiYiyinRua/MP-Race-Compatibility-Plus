# 绮罗勇者多派系开局与演进文化

实现位于 `Source/MultifactionStoryCompatibility`，补充程序集为 `Meow.MultifactionStory.dll`。通过现有 MP-Race-Compatibility-Plus 的 `1.6/Assemblies` 加载，无需替换 Multiplayer 或绮罗原 DLL。所有玩家需要相同的补充程序集并重启游戏。

## 使用

在 Multiplayer 的多派系开局中选择“绮罗勇者”剧本。文化选择页面右上角增加“自定义文化 / 演进文化”，可新建演进文化、固定文化，或复制现有文化。使用原版模因、文化详情、戒律和仪式控件编辑，保存返回后继续配置角色并开局。取消自定义可恢复使用原有预设。

演进文化遵循原版初始模因限制；改革使用 Multiplayer 已有的 `IdeoDevelopmentUtility.ApplyChangesToIdeo` 同步机制。编辑草稿不加入现有派系的文化管理器；最终提交时深度序列化整个草稿，并在各端创建派系时统一分配正式文化与戒律 ID。

## 剧本兼容

- 新派系建图时读取 `AncotLibrary.ScenPart_ForcedStartMap.mapGenerator`，使用原剧本的 `Kiiro_SettlementUnderAssault` 生成村庄、战斗及村庄归属转换。
- 按派系保存开局勇者和开局地图，避免只依赖原模组单人 `StartedNewGame` 的全局勇者字段。
- 为新增派系分别保存牧羊人、流浪者、商人事件的相对计时。
- 定期检查原结局任务的条件，使用该派系勇者及其地图生成原版结局任务；每个已登记派系只提出一次。
- 保存结局任务内原模组遗漏的勇者名字，供任务保存、加载和加入时恢复。

结局门槛没有降低：原脚本要求财富超过 500,000、至少 20 名绮罗殖民者、至少 120 天，开启绮罗故事交互、与绮罗结盟并达到完全信任。勇者必须存活且仍属于相应派系。接受任务后沿原任务的离图、结局字幕及解锁故事叙述者路径执行。

## 范围

目标为安装版 `Ancot.KiiroStoryEventsExpanded`（3036480100）的 1.6 剧本，与当前 H 盘 `rwmt.Multiplayer` 0.11.5 安装版配合。文化扩展不依赖绮罗启用。没有改动原模组文件，也没有自动上传工坊。

这是针对指定功能的精简验证，不代表全部绮罗事件、其他模组组合、异步时间及长时间运行均已穷举测试。此前已经生成的空白地图不会自动重建；村庄生成修正用于新建派系开局。
