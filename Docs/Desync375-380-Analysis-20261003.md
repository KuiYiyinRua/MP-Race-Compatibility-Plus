## 源码与补丁边界

- 安装版 Brothel Colony 源码与 DLL 一致；DLL SHA-256 `80EB64E342A4653CF96FE7E5A4F503CB9DE9857D13D9DA4B1C2C8FC1879B8B48`。`brothel-visitor-installed-il.txt` 验证 `JobDriver_WhoreInvitingVisitors.<MakeNewToils>b__12_2` 恰有两次 `Messages.Message(string, LookTargets, MessageTypeDef, true)`。Multiplayer 自带 `NextMessageIdPatch` 对 `historical=false` 使用本地负 ID，不推进共享 MessageID。3.0.147 只把该流程两条通知在 MP 下改成非历史消息；接客判定、换工作、床位、思想及单机消息历史保持原逻辑。此补丁可切断已观察到的消息 ID 差异，但不能证明没有其他隐藏的模拟状态差异。
- 本机实际 RimWorld `Assembly-CSharp.dll` SHA-256 `8FD7E750A38A856B87004AF7AC91363E8FBFE7C6E362030970FD91BD6E7C3505`。`pitgate-installed-tick-il.txt` 中 `PitGate.Tick` 有两处 MTB：`2,60,1` 属于 `Find.CurrentMap == Map` 条件内的镜头震动；`2,60000,1` 属于真实事件调度。3.0.147 只替换前一处为有作用域的 Rand 调用，作用域使用门体 ID 和共享 tick 派生种子，并在 finally 恢复静态、地图和世界 Rand。实际事件调度 Rand、事件时间与门体状态未改。轨迹只给出 `PitGate.Tick` 动态方法偏移，不能单独证明每次都命中哪处 MTB；四地图下各端当前地图不同是有源码依据的推断。
- 前次 355/356/358 的 Ariandel 本地音乐补丁纳入 DesyncBatch 1.0.8。375–380 仍加载 1.0.7，不能作为它的回归结果。
