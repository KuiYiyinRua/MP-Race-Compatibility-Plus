# 文化 DLC / 任务联机回归说明

在 **Multiplayer** 开启、**Ideology（文化）DLC** 启用且本兼容模组已加载时，建议按下列场景各跑一遍，确认不再出现不同步掉线。

## 前置

- 主机与客户端 **模组列表与顺序一致**。
- 可选：将源码中 `ModDebug.EnableQuestIdeologyTrace` 设为 `true` 后重新编译，可在 `Player.log` 中查看任务补丁是否命中。

## 场景 A：接受文化遗物 / 终端类任务

1. 主持与客户端连入同一存档。
2. 触发与 **圣物 / 终端 / 朝圣** 相关的文化任务（或开发者模式快速接取同类任务）。
3. 在任务界面点击 **接取 / 确认**。
4. **期望**：双方保持连接，无 `Random state` / `deep-saved` 类报错。

## 场景 B：任务阶段刷新与信件

1. 在任务进行过程中推进条件（例如进入任务地图、等待计时、完成子目标）。
2. 若有 **带选项的信件** 弹出，由一名玩家操作接受或拒绝。
3. **期望**：选项结果在双方一致，不因仅一端执行回调而掉线。

## 场景 C：通讯台电商与任务交错

1. 一名玩家通过通讯台打开 **喵喵电商** 并完成一次购买（扣银 + 空投）。
2. 紧接着触发或刷新文化任务（可与 A/B 合并）。
3. **期望**：空投落地与任务 Tick 均不因 Rand 分叉掉线。

## 仍掉线时

请保留 **Multiplayer 生成的 desync 报告** 与 **Player.log** 中含 `MP-Meow` / `Random state` 的片段，便于对照补丁是否需收窄到具体 `QuestPart` / 信件类型。
