# 联机兼容补丁分类开关

入口：游戏选项 → 模组设置 → `[MP] Meow Online Shop Compat` → 页面顶部“联机兼容补丁开关”。

提供一个总开关和 17 个独立分类开关，默认全部开启，旧配置缺少新字段时也保持开启：

- 基础稳定性与存档修复
- 商队、运输与奥德赛飞船
- 多派系、任务与事件
- 性能优化与调度
- 视听效果与随机隔离
- 通用玩法、建筑与操作
- 喵呜网店与通信台
- 米莉拉、米莉安与 Ancot 系列
- 墨萝与相关扩展
- RJW 与相关扩展
- Light350 与秘书系统
- 鼠族、地下鼠与异常扩展
- 沃芬与相关扩展
- 涅瓦莲与相关扩展
- 渡鸦与服装缓存
- 其他种族与扩展
- 近战动画

修改后必须重启游戏。主客机需使用相同设置并全部重启后再联机；重放也需要匹配的补丁配置。关闭兼容补丁可能恢复原有失步问题。

每行显示本次启动采用的状态。总开关关闭时仍保留分类选择；“恢复所有联机补丁为开启”恢复总开关及分类默认值。现有优化预设不会覆盖分类开关。各类原有的细分设置仅在对应分类开启时有作用。

种族、模组专用补丁优先归入对应种族或模组类；例如米莉拉的视效随机补丁属于米莉拉类，通用视效类控制通用视听补丁。混合程序集按其中实际功能分别接入分类，涅瓦莲和米莉拉传说事件不会被捆绑开关。

## 维护与验证

`Source/MP_MeowOnlineShop/CompatibilityPatchCategories.cs` 管理分类及启动快照。配置保存在原有 ModSettings 中：`mp_meow_compatibility_enabled`、`mp_meow_disabled_compatibility_categories`。Harmony 和 Multiplayer 同步注册在启动时被跳过，不执行运行中卸载；现有配置同步逻辑已将本 mod 列为必须重启的配置。

覆盖主入口的 250 个初始化调用、33 个米莉拉附加模块构造器、独立 TPS 启动入口、14 个已安装的附属程序集，以及必要的组件 Tick/Update 和通信台按钮入口。关闭时保留存档数据的序列化，防止再次开启后丢失原有记录。

验证目录：`BuildValidation/CategorySwitches-20260920/`。15 个工程均编译通过，零警告、零错误；380 项开关逻辑与程序集元数据断言通过。15 个 DLL 已复制至实际加载目录并逐一核对 SHA-256。按用户要求，未启动游戏，运行时效果尚未验证。

源文件修改前副本保存在验证目录的 `Before/`，差异在 `changes.diff`。渡鸦加载目录内原有的旧 `.dll` 备份已移至验证目录，避免被游戏当作第二份程序集加载。
