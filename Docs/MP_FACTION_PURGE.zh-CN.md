# 多派系联机：彻底清理玩家派系

> 状态：候选实现，尚未安装或发布。完整模组测试被共享文化仪式记录的居民残留引用拦截；按用户要求，本轮后停止测试。下列操作说明为实现设计，不代表当前版本已可正式使用。

此补丁为服务器主提供一次性维护指令。选择玩家派系后，删除该派系的全部普通基地、基地地图、该派系人物、关联任务及 MP 派系管理数据。基地清理按派系 ID 执行，不依赖当前观察的地图。房主主派系、观战派系和 NPC 派系受保护。

## 菜单与操作

1. 所有联机端使用相同补丁，完全退出游戏再重新启动。
2. 房主开启多派系房间，切回房主主派系，让所有其他玩家和观战者退出。
3. 开启游戏设置中的开发者模式，打开原版 **Debug actions／调试操作** 菜单。
4. 搜索 **MP Purge player faction**，或进入 **Multiplayer local** 分类，选择 **MP Purge player faction / 清理玩家派系**。
5. 选择目标派系。核对派系名称、数字 ID、全部基地、人物和关联任务清单；输入派系数字 ID，点击“备份并清理”。
6. 成功后退出当前房间，从生成的 **After-FactionPurge-…** MP 存档重新开房，再让其他玩家加入。

这是原版开发者操作菜单中的按钮式指令，无需另装控制台模组。选择某个玩家派系会清理其全部普通基地，不能只保留该派系的其中一个基地。

## 备份与故障处理

执行前自动保存 **Before-FactionPurge-派系ID-…** MP 备份。备份写入和索引读取校验成功后才发送清理指令。生成新存档时检查序列化错误和已删除对象的残留引用，再由临时文件改名为正式 ZIP；不覆盖旧存档。

备份及结果位于当前游戏保存目录的 `MpReplays` 文件夹，完成提示会显示完整路径。任何清理或保存错误都会要求恢复 Before 备份。删除过程不能对任意模组实现事务回滚；出现错误后不要继续使用当前世界或覆盖原存档。

进入维护后会暂时拒绝新连接，直至退出并重新开房。清理后世界及保留地图暂停，以免在旧会话继续模拟。等待重新开房期间，殖民者栏及其时间按钮暂时隐藏，避免旧地图缓存被继续绘制；重新开房后恢复。

## 支持范围与拦截条件

目标版本：当前本机 RimWorld 1.6.4850、Multiplayer 0.11.5+4a3be27-dirty。MP 原始 DLL SHA-256：`28D2CDA41D78497970565748BE0E4B7E23F6ECE03310A304359A840AB38FAAD1`。补丁独立编译，不改写 MP 原始 DLL。

下列情况会拒绝清理并显示原因：

- 其他连接尚未退出，或房主没有切回主派系。
- 目标派系有远行队、运输器、特殊据点或关联口袋地图。
- 目标人员或财产仍在保留地图；目标地图内有其他玩家人员、俘虏或财产，包括容器内人员。
- 存在未结束的 MP 交易、仪式、编队等会话，或当前界面正在触发联机暂停锁。仅注册但未生效的旧式暂停锁不会阻止清理。
- 关联任务包含未经适配的第三方 QuestPart，或第三方组件仍保存目标引用。
- 引用扫描超出安全上限，或存档序列化出现警告、错误、残留引用。

共享文化定义保留，避免破坏其他派系正在使用的文化。此工具删除游戏派系实体及所列关联数据；无法保证任意第三方模组的整数 ID 缓存、外部文件或静态缓存都具有可识别的清理接口，因此遇到已识别的不安全关系会停止，而不会盲目改写未知数据。
