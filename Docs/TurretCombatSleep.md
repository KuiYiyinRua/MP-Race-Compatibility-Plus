# 联机炮台战斗休眠

实验组件：`1.6/Assemblies/Meow.TurretCombatSleep.dll`，版本 1.3.0，随本次更新提供但默认关闭。所有联机玩家必须在模组设置中使用相同选项并重启；该设置为本机模组配置，不会自动同步。

打开模组设置中的“启用炮台战斗休眠实验”并在多人模式运行后，玩家所属炮台在本地图没有仍可构成威胁的敌对目标，且没有强制目标、当前目标、预热、冷却、激活射击或持续特效时，可以休眠空闲战斗逻辑。设置默认关闭。无害无阵营角色、非敌对精神状态角色及倒地/死亡角色不再阻止全地图休眠。普通原版、Ancot和渡鸦炮台不再因打猎弹丸保持唤醒；拦截型及未知自定义目标搜索仍保守地关注所有弹丸。出现敌人后，下一次炮台更新直接读取新索引，不存在额外轮询延迟。原炮台自身的索敌间隔保持不变。

保留建筑基础 Tick、供电、燃料、组件更新、独立 TickInterval、子类追加的非战斗逻辑和所有 Harmony Tick 后置补丁。没有改成节电模式，也没有暂停整张地图。正在操作的人工炮台保留正常行为。玩家所属包含已经认领的炮台，不追溯最初建造者。

## 1.2.0 进一步优化

- **共享候选索引**：同一地图目标缓存、同一阵营共用连续候选列表。原版事件更新 HashSet 时，集合身份与版本变化使索引失效；同数量的移除/替换也会刷新。炮台绑定随地图缓存或阵营变化重新获取，读档、重连从当前实体重建，不依赖历史模拟 tick。
- **和平快速路径**：三组目标集合为空时直接返回安全，不分配炮台状态、不建立列表、不遍历目标。非空时复用共享列表和炮台绑定；原有 Ancot 重复 Verb 扫描也合并为一次。所有强制目标、当前目标、操作员、预热、冷却、Verb 和持续特效状态仍实时检查。
- **不缓存可变敌对结论**：候选的出生/销毁、死亡/倒地、恢复站立和针对具体建筑的敌对关系逐次读取。不能只靠“上次休眠”为真就跳过战斗门禁；这样其他模组直接改字段也能被下一次更新看见。拦截型/未知炮台仍实时查看弹丸列表。非空地图判断仍可能是 O(候选数)，不是全场景 O(1)。
- **Raven 中枢耗电查找**：一次 `ManagedTurretPowerConsumption` 求和内只建立一次配置索引，避免每个炮台重复复制 `GetTurretOptions` 列表和线性查找。首次定义优先、空项过滤和原求和顺序保留；炮台存活、耗电字段仍实时读取。索引不跨这次调用，嵌套调用和异常退出会恢复上下文。发现其他模组已修改配置查找/过滤方法时保留原实现。
- **火焰视觉事件休眠**：已存在且不播放的特效停止周期性刷新；喷火切换、生成/移除、读档、偏移/旋转/缩放修改以及位置变化触发更新。中枢重复通知“停止喷火”不会再反复刷新同一闲置特效。活动喷火保持原频率，缺失 Unity 对象每 60 tick 重试。该缓存只影响展示，不参与任何战斗判断。
- 保留 1.1.0 的覆盖范围及基础组件行为。未把建筑从全局 TickList 移除，没有新增 30/60 tick 的战斗唤醒轮询。

当前原版 `GetComp<T>` 已有 `compsByType` 查找索引，因此没有再给全部组件套额外缓存，也没有缓存中枢 `RemoteTurretsOperational`、电力或燃料结果。Raven 火焰炮台的 `RemoveAttachedFire` 和米莉拉独立维修仍执行。Pawn/衣物上的辅助武器不扩大到建筑休眠策略。

## 1.1.0 加强内容（已包含于 1.2.0）

- 将渡鸦防御中枢重复创建 `burstWarmupTicksLeft` 反射访问委托改为复用单一委托。始终读取当前字段值，保留预热倍率计算；即使炮台不能休眠，这部分优化仍生效。检测到独立 `LatestSavePerformance` 模块时交由它处理，避免重复改写。
- Ancot 建筑炮台组件、PLAMilira 建筑炮台组件、渡鸦火焰喷射组件在空闲且地图安全时跳过整个已核对的战斗主体，省去前置状态/属性查询。PLAMilira 的后坐力回正仍执行。没有跳过建筑的其他组件或扩展到角色植入武器。
- 1.1.0 未喷火的渡鸦火焰视觉组件每 60 个模拟 tick 刷新一次；1.2.0 已由上面的事件休眠替代。
- 无人操作的人工炮台/迫击炮也可休眠；原本只有人在操作时才推进的冷却没有被快进或清零。重新操作时恢复原计时。
- 保留实时索引判断，不增加逐地图有状态威胁缓存或仅主机执行的模拟分支。

## 覆盖方式

- 原版 `Building_TurretGun` 及其派生类：在基础组件更新后跳过空闲战斗主体。自定义武器同样纳入，但必须所有 Verb 都处于空闲且没有待维护特效。
- `AncotLibrary.Building_SpinTurretGun` 及其派生类：同样跳过已核对的空闲战斗主体。米莉拉堡垒的自动维修仍由原来的 `TickInterval` 执行。
- 其他符合炮台字段结构的 `Building_Turret` 派生类：自动发现 Def 对应的类及继承链，仅给 Tick 内的自动索敌和已核对的炮塔转动调用增加休眠判断。没有截断整个自定义 Tick。
- 渡鸦路径炮台、火焰炮台：覆盖额外的空闲定向调用；火焰喷射组件无潜在威胁时跳过喷射区域的敌人扫描，已经开始的喷射、冷却、特效和附着火焰清理继续运行。
- 建筑武器组件及其他炮台：使用原版 `BestAttackTarget` / `BestShootTargetFromCurrentPosition` 时，空地图索敌提前返回无目标。这个兜底不停止该组件的其他更新，也不作用于 Pawn 武器或植入炮台。

本地程序集清单识别到 22 个模组 `Building_Turret` 派生类，涵盖：

- 渡鸦 Remote、Pattern、FlamePattern。
- Ancot 旋转与强制瞄准、米莉拉堡垒、米莉安改造 CIWS / Plasma。
- MiliraImperium 普通、无射程、无视视线、阳光塔、拦截型。
- PLAMilira 强制指定目标。
- 沃芬强制瞄准、莫诺琳、Fortified 载员炮台、RimWorldColumns 炮台。
- 尼瓦瑞安瞄准特效、目标校验、冬季炮台、低温迫击炮。

这是安装文件的静态覆盖清单，不代表这些模组都在当前存档启用，也不代表每种自定义炮台的全部逻辑都已休眠。实际加载的类型和调用点在启动日志 `PROFILE` / `GUARDED` 中列出。字段结构不符合要求的类型保留原逻辑；原版索敌接口的兜底仍可独立生效。未经过原版索敌接口的其他完全自定义武器，不宣称自动覆盖。

## 联机与回退

没有新增存档状态、可变威胁结论缓存、现实时间计时器或各客户端独立的设置。读取的是当前炮台地图、所属阵营与游戏现有目标索引；1.2.0 的派生索引通过集合身份/版本校验，且始终读取候选当前状态。运行时集合版本字段不支持时回退原逐集合检查。视觉状态缓存与模拟完全隔离。非倒地敌人、虫巢守卫等仍可能保守地阻止炮台休眠。

全部联机参与者需要相同 DLL，并完全重启游戏。需要回退时，所有参与者退出游戏，将这个增量 DLL 移出加载目录后重启；无需修改存档。
