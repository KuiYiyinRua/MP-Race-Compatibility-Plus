# 2026-09-09 工坊与源码更新

本次更新完成 Nivarian Race（3624805128）、Monolyn Race（3742031864）和 VoiceroidAsAnimal（2073559411）的主要操作联机兼容补充，并将已有的本地 3.0.125 生产源码同步到仓库。不是将所有历史功能重新测试一遍；本次双端运行范围详见 [三种族测试记录](Nivarian-Monolyn-Voiceroid-Multiplayer.md)。

## 实现与文件

- `Source/RaceTrioCompatibility/`：新补充程序集，通过 Harmony 拦截 UI 入口、MP 同步命令/字段、对象 worker 以及确定性随机键处理三个模组。单机保留原操作；多人模式重放改变模拟状态的操作。各模块入口和已测试路径见专项记录。
- `Source/MP_MeowOnlineShop/`：同步本地已有 3.0.125 核心生产源文件及明确的 Compile 清单，包括补充程序集所使用的 Monolyn 字段/操作注册。源仓库此前停在 3.0.115，故此部分包含既有本地修复，不将它们全部归为本次三种族新增代码。
- `Source/MeleeAnimationCompat/`、`Source/RavenCompatibility/`：同步当前工坊包已有的可选生产程序集源码，与 LoadFolders 条件一致。
- `About/About.xml`、`LoadFolders.xml`、语言资源、兼容列表与中英文工坊介绍：对应当前发布布局。当前包 ID 为 `local.mp.meowonlineshop.sellslingshot`，主客机必须使用同一包 ID、版本和文件。

## 实际验证

隔离环境：RimWorld 1.6.4871，Multiplayer 0.11.5+a481546，三个目标同时启用、HAR/Harmony/Prepatcher 及全部官方 DLC。基础组合由客户端发起操作；第二组合增加官方 Multiplayer Compatibility，由主机发起操作。两轮每端六阶段状态断言全部通过，各推进 15,960 地图 tick，未检测到不同步。按用户要求未做极端、边缘或长时测试；一次银币夹具失败保留在专项记录中，不计通过。

独立 GitHub 克隆内，核心、三种族、MeleeAnimation 和 Raven 四个项目均 Release 编译通过，零警告、零错误。编译使用本机合法安装的 RimWorld、Harmony、Multiplayer 及 Animation 依赖，未把依赖 DLL 纳入源码提交。工坊上传的是之前实际双端测试的冻结 DLL，没有用这次克隆的重新编译结果替换它们。
