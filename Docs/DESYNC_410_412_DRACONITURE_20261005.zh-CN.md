# Desync-410/411/412 修复与本地部署

兼容包版本：3.0.149。TaleNivarian 模块：1.1.4.0。主模块仍为 3.0.148.0，原有 Perspective Shift 新房间释放旧主角认定、重连重新认定与旧输入失效保护保留。

## 原因与改动

实际目标是当前 H 盘 `3686517288` 的 Nivarian Draconiture。`NivarianRace.DraconicMilitary.EngineeringDroneThing` 虽使用 DraconicMilitary 命名空间，却位于家具模组 DLL。目标 MVID 为 `c7613a3a-06ad-4b93-8a2e-cf998194164a`，与用户日志一致。

`TickThrowWords` 使用本地语音开关和未存档的静态飘字限流队列。重进或重连后，两端可能分别走“只生成等待时间”和“继续随机选词”的分支，从共享 Rand 消耗不同数量的随机数。410、412 在相同输入随机状态后出现该分支差异；411 的记录窗口开始时已有随机偏移，单独不能确定更早的首个原因。

补丁只在联机时给这一飘字方法加独立随机状态，种子由固定标识、无人机 ID 和游戏 tick 组成；finalizer 恢复原随机状态，包括异常退出。无人机的修理、建造、移动逻辑未纳入随机隔离。单机行为保持原状。

调整代码已成功编译，部署使用同一 Candidate1 文件。用户要求停止测试之前，旧版复现了两端随机消耗差异及不同步；新版完成了单图 10000 tick 专项回归。双图、冷重连、异步时间和长时运行的完整验收未完成，部分回归因测试夹具失败或中断，不能计为通过。完整 320 模组代表回放还存在重复空 LoadID 登记和双端可用内存限制，未完成双端验收。
