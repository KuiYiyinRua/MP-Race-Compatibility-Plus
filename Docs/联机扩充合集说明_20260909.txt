[h2]收录依据[/h2]
收录官方数据库评分4的模组、当前官方兼容程序集有对应支持的模组、本补丁已有专项适配，以及没有独立程序集的XML/贴图/汉化内容。存在已知联机错误时，不因它是XML模组或曾有官方兼容代码就直接放行。
官方数据库的低评分如果明确写明“需要Multiplayer Compatibility”，会检查具体补丁后再判断；其他标明仍会失步、加入失败或主要功能不可用的模组暂不加入。
无工坊ID、无法公开访问、缺少可推荐前置、不支持1.6、已知冲突和重复工坊条目已筛除。部分多目标汉化包涵盖本合集之外的模组，只使用已选本体对应译文即可，无需为汉化启用所有额外目标。

[h2]有条件使用[/h2]
[list]
[*]Allow Tool：仅推荐共同派系；关闭 Storage space alert（储存空间警报）。官方记录指出多派系模式使用 Allow all 会失步。
[*]Exosuit Framework：必须配合官方Multiplayer Compatibility。框架获得适配不代表所有依赖它的外骨骼内容都兼容；有明确故障记录的内容未纳入。
[*]本库选择 Vanilla Psycasts Expanded，未同时加入与其声明冲突的 Choice Of Psycasts。
[*]Dubs Performance Analyzer 与 Facial Animation 合用时，关闭 reduce stutters while panning。Dubs Mint Menus 关闭 plant menus（种植菜单）。
[*]Facial Animation Experimentals 的 Face Select 修改由主机完成，其他玩家重连后查看。Vanilla Expanded Framework 避免取消雇佣兵合同；Replace Stuff 使用直接覆盖建造，Replace按钮目前有功能限制。
[*]官方评分4也可能带版本或功能备注，不能把评分单独当作全功能认证；性能类扩展按需选用，不要把合集里所有性能方案一起打开。
[*]不要另外叠加 RimThreaded、Slower Pawn Tick Rate、TPS Optimizer、Performance Esmolas 等不同Tick/线程调度方案。Performance Optimizer 使用本补丁专项适配，与这些模组不同。
[/list]
