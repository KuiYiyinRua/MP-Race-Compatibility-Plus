# Desync 36–41：日志分析与修复边界

## 已修复的实际错误

本轮拿到 36、37、39、40、41 五个包；用户确认跳过缺失的 38。原始 ZIP 已冻结到
`BuildValidation/DesyncEvidence/Desync36-41_20260912`，逐个核对复制前后 SHA-256。
日志已经包含 Almost There 夜休缓存修复的启动标记，本轮没有撤回或再次改写那项修复。

1. **YaOpt 1.1.4 与 Kingfisher 0.7.4 / PurePatcher 1.8 的删除索引兼容错误。**
   安装版 YaOpt 转译器写死 `ThingRequestGroup` 局部变量槽 6；安装版 Kingfisher 的实际槽是 4。
   槽 6 此时属于转译器新增的索引对象，传给接收枚举的函数会在 Unity Mono 产生非法 IL。
   原日志明确记录此删除补丁失败及大量重复索引报错。
   此外，PurePatcher 将方法正文复制进 `Verse.ListerThings.Remove`；只修补 Kingfisher 注解源方法，
   不会修复实际删除入口。首次隔离测试中，两端各做 100 次删除／重加，均出现 99 次重复索引，证明仅修槽号不足。
   最终补丁同时识别实际入口、按类型解析槽号，保留 YaOpt 成对的添加／删除索引维护。
2. **多派系设置页注册失败。**
   Harmony 拒绝以派生页的反射对象注册继承的 `Window.PreOpen`。
   现将每个方法归一到实际声明类型，再去重注册；原有页面实例弱表及场景恢复范围保留。
   实机验证两端均成功注册 17 个页面目标。

这两项是日志和安装版代码中已核实、并经实机验证的错误。尚不能把它们说成五个掉线包全部根因。

## 各包的首次可见分歧

五个包的 80 条上下文记录中，前 40 条完全一致。忽略因插入记录而平移的 trace 编号后：

  Anomaly 组件抽样一次、年龄逆转需求重置抽样五次。之后地图上的 Cumpilation 抽样仍能对齐。
  不能仅凭这一窗口认定 Cumpilation 或技能 getter 是造成整局地图随机状态分叉的根因。
- **37：**最后有效 tick 1921681；首差 1921738，trace 2399。

  窗口没有记录这些输入，无法确定具体哪个 pawn／条件先分叉。

  主机对 `Corpse_Alien_CarniMama138160` 执行腐烂损伤，多出 3 次抽样：腐烂数值取整、
  DamageInfo、DamageWorker 取整。其他地图记录可继续对齐。
  缺少两端尸体位置、温度、腐烂进度及储藏供电状态，尚不能选定上游原因。
- **40：**最后有效 tick 2138101；首差 2138135，trace 225。
  主机的 `Kiiro_Race99633` 搬运拆堆多分配一次 Thing ID；后续窗口中的随机数对齐。

  客户端的 `Kiiro_Race99687` 搬运拆堆多分配一次 Thing ID；后续窗口中的随机数对齐。
  40、41 不能只根据这条记录就修改搬运数量、路径或吞掉 ID 分配。

36 的日志明确报 `Wrong random state on map 1`。37–41 的 `local_logs.txt` 是累计且已截断的旧进程日志，
其中保留的 36 号报错不能当作每个后续包的报错原因。
日志还保留了核心配置不同、热同步要求重启后仍选择强制加入的记录；这是需要处理的输入差异，
但不等于已经证明五次掉线都由该配置导致。

## 使用

所有玩家退出游戏后使用同一份补丁 DLL；加入时先处理配置差异，使用联机原生的修复并重启流程。
补丁不会追溯修正已经在某一端分叉的内存状态，需要从同一主机存档重新加入。
不要根据本报告单独禁用 Cumpilation、近战动画或修改全局随机数校验。
